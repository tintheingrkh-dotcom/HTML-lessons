## 🗺️ အသေးစိတ် သင်ရိုးညွှန်းတမ်း (Syllabus & Roadmap)

### 🧱 Module 1: HTML Fundamentals (အခြေခံအုတ်မြစ်)
* **1.1 Web Basics & HTML Introduction:** Internet vs Web, Client & Server, Web Browser အလုပ်လုပ်ပုံ၊ Website vs Webpage၊ HTML, CSS, JS တို့ရဲ့ တာဝန်များ။
* **1.2 HTML Tags & Attributes:** Tags အမျိုးအစားများ၊ Nested & Empty Elements, Attributes များနှင့် Global Attributes (`id`, `class`, `title`, `style`, `hidden`, `lang`)။
* **1.3 HTML Document Structure:** `<!DOCTYPE html>`, `<html>`, `<head>`, `<body>` နှင့် Boilerplate Template တည်ဆောက်ပုံ။
* **1.4 Headings & Typography:** `<h1>` မှ `<h6>` အထိ အသုံးပြုပုံနှင့် SEO အတွက် Heading Hierarchy သတ်မှတ်ပုံ။
* **1.5 Text Formatting:** `<p>`, `<br>`, `<hr>`, `<strong>`, `<em>`, `<mark>`, `<del>`, `<ins>` စသည့် စာသားပြင်ဆင်မှုများ။
* **1.6 Advanced Text Elements:** `<blockquote>`, `<pre>`, `<code>`, `<kbd>`, `<sub>`, `<sup>`, `<abbr>` အဆင့်မြင့်စာသားများ။
* **1.7 Comments & Entities:** `` ရေးနည်းနှင့် HTML Entities ဝင်္ကပါများ (`&lt;`, `&gt;`, `&amp;`, `&nbsp;`, `&copy;`)။

### 🔗 Module 2: Links, Lists & Media
* **2.1 Lists:** Unordered (`<ul>`), Ordered (`<ol>`), Nested နှင့် Description List (`<dl>`)။
* **2.2 Hyperlinks:** External/Internal Links, Email, Telephone, Download နှင့် Anchor Links များ။
* **2.3 File Paths:** Relative vs Absolute Path ကွာခြားချက်နှင့် Folder Structure စနစ်။
* **2.4 Images & Figures:** `<img>` tag, `src`, `alt` အသုံးပြုပုံနှင့် `loading="lazy"` ဖြင့် Speed မြှင့်ခြင်း၊ `<figure>`, `<figcaption>`။
* **2.5 Audio & Video:** Multimedia များ ထည့်သွင်းခြင်း (`<audio>`, `<video>`, `<source>`, `<track>`, poster, controls)။
* **2.6 iframe:** YouTube ဗီဒီယိုများနှင့် Google Maps များ ထည့်သွင်းခြင်းနှင့် Security Basics။
* **2.7 Favicon:** Website Logo ချိတ်ဆက်ခြင်း။

### 📊 Module 3: Tables & Layout
* **3.1 HTML Tables:** `<table>`, `<tr>`, `<td>`, `<th>`, `<caption>` ဖြင့် ဇယားဆွဲခြင်း။
* **3.2 Advanced Tables:** `colspan`, `rowspan`, `<thead>`, `<tbody>`, `<tfoot>` အဆင့်မြင့်ဇယားများ။
* **3.3 Block vs Inline:** Elements တွေရဲ့ သဘာဝနှင့် `<div>` vs `<span>` အသုံးပြုပုံ။
* **3.4 Semantic HTML5:** `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`, `<details>`, `<summary>` စသည့် ခေတ်မှီ Layout ရေးဆွဲနည်း။

### 📝 Module 4: Forms & User Input
* **4.1 Form Basics:** `<form>` တည်ဆောက်ပုံ၊ `action`, `method` (`GET`/`POST`) အလုပ်လုပ်ပုံ။
* **4.2 Input Types:** text, password, email, number, date, color, range, file, tel နှင့် Submit Button အမျိုးအစားများ။
* **4.3 Selection Controls:** Radio, Checkbox, `<select>`, `<option>`, `<optgroup>`, `<datalist>`။
* **4.4 Form Validation:** `fieldset`, `legend`, `required`, `pattern`, `min/max`, `placeholder`, `disabled` စသည့် စည်းကမ်းသတ်မှတ်ချက်များ။

### 🌐 Module 5: Metadata, SEO & Accessibility (a11y)
* **5.1 Head Element & SEO:** Title, Meta Description, Viewport နှင့် Semantic Layout အသုံးပြု၍ Google ရှာဖွေမှုတွင် ထိပ်ဆုံးရောက်အောင် လုပ်ခြင်း။
* **5.2 Open Graph:** Facebook/Viber တွင် Link ချပြလျှင် ပုံနှင့်စာပေါ်အောင် လုပ်နည်း (`og:title`, `og:image`)။
* **5.3 Accessibility (a11y):** မျက်မမြင်များအတွက် Screen Readers စနစ်၊ ARIA Basics နှင့် Keyboard Navigation စံနှုန်းများ။

### 🛠️ Module 6 to 8: Best Practices & Publishing
* **6.1 Clean Code:** စနစ်ကျသော ကုဒ်ရေးသားနည်း၊ W3C HTML Validation နှင့် အမှားနည်းအောင် ရေးနည်း။
* **6.2 Browser DevTools:** Chrome/Firefox Tools များဖြင့် ကုဒ်စစ်ဆေးခြင်း (Inspect Element, Console, Responsive Mode)။
* **6.3 Website Deploy:** GitHub Pages, Netlify, Vercel တို့ပေါ်သို့ Website အခမဲ့ လွှင့်တင်ခြင်း။
