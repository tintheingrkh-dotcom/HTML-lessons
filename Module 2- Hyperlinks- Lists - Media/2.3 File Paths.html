2.3: File Paths

HTML မှာ File Paths ဆိုတာ Website တစ်ခုထဲမှာရှိတဲ့ တခြား ဖိုင်တွေ (ဥပမာ - ဓာတ်ပုံများ၊ CSS ဖိုင်များ၊ တခြား HTML စာမျက်နှာများ) ကို ချိတ်ဆက်ပေးဖို့ ဖိုင်တည်နေရာလမ်းကြောင်း ညွှန်းပေးတာ ဖြစ်ပါတယ်။ <img>, <link>, <a>, <script> စတဲ့ tag တွေမှာ ဖိုင်လမ်းကြောင်းကို အဓိက အသုံးပြုကြပါတယ်။ HTML မှာ File Path (၂) မျိုး ရှိပါတယ် -

  • Relative File Paths (အနီးစပ်ဆုံး ဖိုင်လမ်းကြောင်း)
  • Absolute Path (အပြည့်အစုံ ဖိုင်လမ်းကြောင်း)
  • သတိထားရမည့် အချက်များ

A. Relative File Paths (အနီးစပ်ဆုံး ဖိုင်လမ်းကြောင်း)

မိမိ ရေးနေတဲ့ HTML ဖိုင်တည်ရှိရာ Folder အပေါ် မူတည်ပြီး ဖိုင်လမ်းကြောင်း ညွှန်းတာ ဖြစ်ပါတယ်။ Website တည်ဆောက်တဲ့အခါ ဒါကို အသုံးအများဆုံးပါပဲ။ အသုံးများတဲ့ သင်္ကေတများနဲ့ ရေးသားပုံ -

  • ./ လက်ရှိဖိုင်တွဲ (Current Directory) ဒီသင်္ကေတက ရှိလည်းရှိ၊ မရှိလည်းရှိ။ ဒါပေမယ့် ရှင်းရှင်းလင်းလင်းဖြစ်အောင် ထည့်ရေးလေ့ရှိတယ်။
  • folder/filename လက်ရှိ ဖိုင်တွဲထဲက နောက်ထပ် ဖိုင်တွဲတစ်ခုထဲမှာ ရှိနေရင်သုံးပါတယ်။
  • ../ အထက်ဖိုင်တွဲ (Parent Directory) တစ်ဆင့်အထက်ကို ပြန်တက်ချင်ရင် သုံးတယ်။ နှစ်ဆင့်တက်ချင်ရင် ../../ လို့ရေးတယ်။

B. Absolute File Paths (အပြည့်အစုံ ဖိုင်လမ်းကြောင်း)

ဒါWebsite တစ်ခုခုရဲ့ URL လိပ်စာအပြည့်အစုံ (Web Address) ကို တိုက်ရိုက် ညွှန်းပေးတာ ဖြစ်ပါတယ်။ တခြား Internet ပေါ်က Website တွေမှာရှိတဲ့ ပုံတွေ၊ ဖိုင်တွေကို ယူသုံးချင်တဲ့အခါ သုံးပါတယ်။ https:// နဲ့စတယ်။

ဥပမာ -
<img src="https://www.w3schools.com/images/w3schools_green.jpg">

သတိပေးချက် – တစ်ခြား Server ပေါ်က ဖိုင်ကို ခေါ်ရင် သူတို့ Server ကျသွားရင် သင့်ပုံပါ ပျက်သွားမယ်။ ဒါကြောင့် ကိုယ်ပိုင် Project ဖိုင်တွေကို ဒီလိုမခေါ်ပါနဲ့။

C. Root-relative Path (/)

ဒါက Slash (/) နဲ့စတယ်။ ဒါက လက်ရှိဖိုင်ဘယ်မှာရှိလဲ မကြည့်ဘဲ Website ရဲ့ အမြစ်တွဲ (Root Directory) ကနေ စရှာတယ်။
ဥပမာ - သင့် Website က www.mywebsite.com မှာရှိရင်၊ /images/photo.jpg ဆိုတာက www.mywebsite.com/images/photo.jpg ကိုညွှန်တယ်။
ဒါကိုဘယ်အချိန်သုံးမလဲဆိုတော့ PHP, Python (Backend) လိုမျိုး Server-side ပရိုဂရမ်းမင်းတွေနဲ့ အလုပ်လုပ်တဲ့အခါ သုံးတယ်။ ဒါပေမယ့် လက်ရှိ သင်လေ့လာနေတဲ့ ရိုးရိုး HTML ဖိုင်တွေအတွက် မသုံးဖို့ အကြံပြုတယ် (ဘာလို့လဲဆိုတော့ ကိုယ့် Computer မှာ Local ဖွင့်ရင် အလုပ်မလုပ်လို့ပါ)။ လက်ရှိအဆင့်မှာ ../ နဲ့ ./ ကိုပဲ ကျွမ်းကျင်အောင်လုပ်ပါ။

D. သတိထားရမည့် အချက်များ

  • Case Sensitivity (စာလုံးအကြီးအသေး) – ဖိုင်တွဲနာမည်က Images ဆိုရင် images လို့ ရေးလို့မရဘူး။ အထူးသဖြင့် Server (Linux) တွေပေါ်မှာ စာလုံးအကြီးအသေးကို အထိခိုက်ဆုံးပါ။ အကုန် lowercase (အသေး) နဲ့ပဲ နာမည်ပေးပါ။
  • Slash (/) နေရာချခြင်း – ဖိုင်တွဲတစ်ခုထဲဆင်းချင်ရင် ရှေ့ကနေ / ထည့်ပါ။ images/profile.jpg (မှန်)၊ imagesprofile.jpg (မှား - ဖိုင်တွဲမပါဘဲ ဖိုင်တစ်ခုတည်းလို့ထင်မယ်)။
  • များလွန်းတဲ့ ../ – သုံးဆင့်၊ လေးဆင့် ပြန်တက်ရင် ကုဒ်တွေ ရှုပ်သွားတတ်တယ်။ ဒါကြောင့် Folder Structure ကို အတတ်နိုင်ဆုံး အနက် (၂) ဆင့် ထက်မပိုအောင် ထားပါ။
  • ဖိုင်နာမည်တွေမှာ နေရာလွတ် (Space) မထည့်ပါနဲ့ – my photo.jpg ဆိုတာထက် my-photo.jpg သို့ my_photo.jpg လို့ ရေးပါ။ Browser တွေ ရှုပ်တတ်တယ်။
  • ဖိုင်တွေကို စနစ်တကျထားပါ – ပုံတွေအတွက် images/၊ CSS အတွက် css/၊ JS အတွက် js/ ဆိုပြီး ခွဲထားပါ။ နောက်ပိုင်း ကြီးမားတဲ့ Project တွေအတွက် အလေ့အကျင့်ကောင်းတစ်ခုပါ။
• ဖိုင်ဖွဲ့စည်းပုံ နမူနာ -
