2.2: Hypelinks - <a> Tag

Hyperlinks (ဟိုက်ပါလင့်ခ်များ) ဆိုတာ Website တစ်ခုရဲ့ အသက်သွေးကြောလို့ ပြောလို့ရပါတယ်။
စာမျက်နှာတစ်ခုကနေ တစ်ခုကို ကူးပြောင်းဖို့၊ တခြား Website တွေဆီ ချိတ်ဆက်ဖို့ ဒါမှမဟုတ် ဖိုင်တွေ ဒေါင်းလုဒ်လုပ်ဖို့အတွက် Hyperlink တွေကို သုံးပါတယ်။
HTML မှာတော့ သူ့ကို Anchor Tag (<a>) နဲ့ တည်ဆောက်ပါတယ်။

  • External Links (အခြား Website များ) နဲ့ Internal Links (ကိုယ်ပိုင် Page များ)
  • target="_blank" နဲ့ လုံခြုံရေးအတွက် rel="noopener noreferrer"
  • Email Link (mailto:) နဲ့ Phone Link (tel:)
  • Page Jump သို့မဟုတ် Anchor Links (Bookmarking)
  • Download Attribute (ဖိုင်ဒေါင်းလုဒ်ချရန်)

A. Hyperlink - <a> Tag ရဲ့ ဖွဲ့စည်းပုံ

Hyperlink တစ်ခု တည်ဆောက်ဖို့ အနည်းဆုံး အချက် ၂ ချက် လိုအပ်ပါတယ်။

  1. လိပ်စာ (URL): ဘယ်သွားမလဲဆိုတဲ့ လမ်းကြောင်း။
  2. ပြသမည့်စာသား (Link Text): အသုံးပြုသူ နှိပ်ဖို့ မြင်ရမည့် စာသား။
ဥပမာ –
<a href="https://www.google.com">Google သို့သွားရန်</a>
ရှင်းလင်းချက် -
  • <a> : Anchor Tag ဖြစ်ပါတယ်။
  • href : Hypertext Reference ရဲ့ အတိုကောက်ဖြစ်ပြီး သွားချင်တဲ့ လိပ်စာ (URL) ကို ထည့်ရတဲ့ Attribute ဖြစ်ပါတယ်။
  • Google သို့သွားရန် : ဒါကတော့ User တွေ မြင်ရပြီး နှိပ်ရမယ့် စာသား (Anchor Text) ဖြစ်ပါတယ်။
    • ရလာဒ် -
    Google သို့သွားရန်

    " Google ကိုသွားရန် "ဆိုတဲ့ စာသားက အပြာရောင်၊ အောက်မျဉ်းကြောင်းပါတဲ့ လင့်ခ်အဖြစ် ပေါ်လာမယ်။ နှိပ်လိုက်ရင် Google စာမျက်နှာကို ရောက်သွားမယ်။

    i. External Links (ပြင်ပလင့်ခ် – တစ်ခြား Website ကိုသွားခြင်း)

    ဒါက တခြား Website တစ်ခုကို သွားချင်ရင် သုံးတယ်။ href ထဲမှာ အပြည့်အစုံလိပ်စာ (Full URL) ကို ထည့်ရတယ်။ (အစမှာ https:// ပါရမယ်။)

    • ဥပမာ ကတော့ အပေါ်က Google သို့သွားရန် ဥပမာ အတိုင်းဖြစ်ပါတယ်။

    ii. Internal Links (အတွင်းလင့်ခ် – ကိုယ့် Website ထဲက စာမျက်နှာများ)

    ဒါက သင့် Website ထဲမှာရှိတဲ့ တစ်ခြား HTML စာမျက်နှာ ကိုသွားချင်ရင် သုံးတယ်။ href ထဲမှာ ဖိုင်နာမည် (File Path) ကိုထည့်တယ်။

    B. Target Attribute (link ဖွင့်မည့်ပုံစံ)

    လင့်ခ်တစ်ခုကို နှိပ်လိုက်ရင် လက်ရှိ Tab မှာပဲ ပွင့်မလား၊ Tab အသစ်နဲ့ ပွင့်မလားဆိုတာကို target attribute နဲ့ ထိန်းချုပ်ပါတယ်။

    • target="_self" – နေရာတူ (လက်ရှိ Tab ထဲမှာပဲ ပွင့်မယ်) ဒါက ပုံမှန်ပါ။
    • target="_blank" – Tab အသစ် ဖွင့်ပြီး သွားမယ်။
    ဥပမာ -
    <a href="https://www.wikipedia.org" target="_blank">Wikipedia ကို Tab အသစ်နဲ့ဖွင့်မယ်</a>
    ရလာဒ် -
    Wikipedia ကို Tab အသစ်နဲ့ဖွင့်မယ်

    C. လုံခြုံရေးအတွက် rel="noopener noreferrer"

    target="_blank" သုံးရင် အနောက်ကနေ rel="noopener noreferrer" တွဲထည့်ပေးဖို့ မဖြစ်မနေ လိုအပ်ပါတယ်။
    Tab အသစ်ဖွင့်ပြီး တခြား Security မကောင်းတဲ့ Website (သို့) malicious website တစ်ခုဆီ လင့်ခ်ချိတ်မိတဲ့အခါTarget Page ကနေ ကိုယ့်ရဲ့ မူလ Page ကို window.opener ဆိုတဲ့ JavaScript object ကနေတစ်ဆင့် လှမ်းပြီး ထိန်းချုပ်လို့ ရသွားပါတယ်။
    ဥပမာ- ကိုယ့် Website စာမျက်နှာကို Fake Login Page အတုကြီး ပြောင်းပစ်လိုက်ပြီး User ရဲ့ Password တွေကို ခိုးယူတာမျိုး (Phishing) လုပ်နိုင်ပါတယ်။

    ဥပမာ -
    <a href="https://google.com" target="_blank" rel="noopener noreferrer">Google သို့ လုံခြုံစွာ သွားရန်</a>
    ရလာဒ် -
    Google သို့ လုံခြုံစွာ သွားရန်

    •တစ်ချို့ Browser တွေမှာ Unvisited Link အဖြစ် ဆက်ပြနေ။
    • ဒါကို အကောင်းဆုံး Practice (Best Practice) အနေနဲ့ အမြဲသုံးပါ။

    D. Email Link (mailto:) နဲ့ Phone Link (tel:)

    ဒါတွေက သုံးစွဲသူကို အီးမေးလ်ပို့ဖို့ ဒါမှမဟုတ် ဖုန်းခေါ်ဖို့ ခလုတ်လုပ်ပေးတယ်။

    • mailto: – သုံးစွဲသူရဲ့ Default Email App ကိုဖွင့်ပြီး လိပ်စာထည့်ပေးတယ်။
    • tel: – သုံးစွဲသူရဲ့ ဖုန်းကို ခေါ်ဆိုမှုစဖို့ ပြင်ဆင်ပေးတယ်။
    ဥပမာ -
    <a href="mailto:tintheing.rkh@gmail.com">ကျွန်တော့်ကို အီးမေးလ်ပို့ပါ</a>
    <a href="tel:+959123456789">ဖုန်းဆက်ပါ (၀၉ ၁၂၃ ၄၅၆ ၇၈၉)</a>
    ရလာဒ် -
    ကျွန်တော့်ကို အီးမေးလ်ပို့ပါ
    ဖုန်းဆက်ပါ (၀၉ ၁၂၃ ၄၅၆ ၇၈၉)

    E. Page Jump သို့မဟုတ် Anchor Links (Bookmarking)

    စာမျက်နှာတစ်ခုတည်းမှာတင် အချက်အလက်တွေ အများကြီးရှိတဲ့အခါ (ဥပမာ - Wikipedia Page တွေ၊ Terms & Conditions Page တွေမှာ) User တွေ အပေါ်အောက် အလွယ်တကူ ခုန်ကူးဖတ်ရှုနိုင်အောင် သုံးတာ ဖြစ်ပါတယ်။ သူ့ရဲ့ အဓိက လျှို့ဝှက်ချက်ကတော့ id Attribute နဲ့ # (Hashtag) ကို တွဲဖက် အလုပ်လုပ်စေတာပါပဲ။

    • အရင်ဆုံး သွားချင်တဲ့ ခေါင်းစဉ် (သို့မဟုတ်) Section နေရာမှာ id တစ်ခု သတ်မှတ်ပေးရပါမယ်။ (id နာမည်ကို ကြိုက်တာပေးလို့ရပါတယ်)

    • ဥပမာ အနေနဲ့ ကျွန်တော်တို့က ဒီ web page ရဲ့ D. Email Link (mailto:) နဲ့ Phone Link (tel:) သင်ခန်းစာကို ခုန်ပြီးသွားချင်တယ် ဆိုပါစို့။ သူ့ကို သွားပြီး ID တစ်ခုသွားပေးရပါမယ် -
    <h2 id="D">D. Email Link (mailto:) နဲ့ Phone Link (tel:)</h2>
    • ID ကို D လို့ပဲ အလွယ်ပေးလိုက်ပါတယ်

    • ဒုတိယအဆင့်အနေနဲ့ နှိပ်ရမယ့် <a> tag ရဲ့ href ထဲမှာ စောစောက ပေးခဲ့တဲ့ id နာမည်ရဲ့ အရှေ့မှာ # ခံပြီး ရေးပေးရပါမယ်။ (# ရဲ့ သဘောက "ဒီစာမျက်နှာထဲက id ကို ရှာပါ" လို့ အဓိပ္ပာယ်ရပါတယ်)

    <a href="#D">D. Email Link (mailto:) နဲ့ Phone Link (tel:)</a>

    • နှိပ်လိုက်ရင် ID ပေးထားတဲ့ ခေါင်းစဉ် D. Email Link (mailto:) နဲ့ Phone Link (tel:) ဆီကိုခုန်ကူးသွားမှာပဲ ဖြစ်ပါတယ်။

    တကယ်လို့ web page ရဲ့ အပေါ်ဆုံးကို သွားချင်ရင် <a> Tag ရဲ့ "href" attribute မှာ #top ဆိုပြီး တန်းထည့်ရုံပါပဲ။ ID ပေးစရာမလိုပါဘူး။ Browser သူ့ဘာသာသူ သိပါတယ်။

    <a href="#top">အပေါ်ဆုံးသို့သွားရန်</a>

    F. Download Attribute (ဖိုင်ဒေါင်းလုဒ်ချရန်)

    HTML က <a> (Anchor) tag ထဲမှာ သုံးတဲ့ download attribute ဆိုတာ လင့်ခ်တစ်ခုကို နှိပ်လိုက်တဲ့အခါ အဲဒီဖိုင်ကို Browser မှာ တိုက်ရိုက်မပွင့်စေဘဲ User ရဲ့ စက်ထဲကို ဖိုင်အဖြစ် ဒေါင်းလုဒ် (Download) ဆွဲချပေးဖို့ အမိန့်ပေးတဲ့ attribute ဖြစ်ပါတယ်။
    ဥပမာ - ပုံမှန်ဆိုရင် PDF ဖိုင် ဒါမှမဟုတ် ဓာတ်ပုံလင့်ခ်တစ်ခုကို နှိပ်ရင် Browser ထဲမှာပဲ ပွင့်လာတတ်ပါတယ်။ အဲလိုမပွင့်ဘဲ စက်ထဲ တန်းဒေါင်းချင်ရင် download attribute ကို သုံးရပါတယ်။
    • Download ပုံစံ (၂) မျိုးရှိပါတယ် -
