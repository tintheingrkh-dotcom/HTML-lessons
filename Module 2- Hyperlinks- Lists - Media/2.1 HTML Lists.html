2.1: HTML list (စာရင်းများ)

website ပေါမှာ စာရင်း ကိုပြချင်တဲ့အချိန် သုံးရန်။HTML မှာ စာရင်းအမျိုးအစား (၃) မျိုးရှိတယ်။
• Unordered List (<ul>, <li>) – မှတ်စု စာရင်း
• Ordered List (<ol>, <li>) – အစဉ်လိုက် စာရင်း (start, reversed, type)
• Description List (<dl>, <dt>, <dd>) – ဖော်ပြချက် စာရင်း
• Nested Lists – စာရင်းထဲမှာ စာရင်းထပ်ထည့်ခြင်း

A. Unordered List - မှတ်စု စာရင်း(<ul< & <li>)

ဒီစာရင်းက အစဉ်လိုက်မဟုတ်ဘဲ items(ပစ္စည်းတွေ)ကို စုစည်းပြသဖို့သုံးတယ်။ ဘေးမှာ (Bullet point - •) ပါတယ်။
• <ul> = Unordered List (list Tag)
• <li> = List Item (စာရင်းထဲက item)

ဥပမာ - 

<ul>
    <li>ကြက်ဥ</li>
    <li>ထမင်း</li>
    <li>ဟင်းသီးဟင်းရွက်</li>
    <li>ငါးပိ</li>
</ul>
ရလာဒ် -
  • ကြက်ဥ
  • ထမင်း
  • ဟင်းသီးဟင်းရွက်
  • ငါးပိ

B. Ordered List (အစဉ်လိုက်စာရင်း) – <ol> & <li>

ဒီစာရင်းက အစဉ်လိုက် (ပထမ၊ ဒုတိယ၊ တတိယ...) အရေးကြီးတဲ့ စာရင်းမျိုးအတွက်သုံးတယ်။ ပုံမှန်အားဖြင့် ဘေးမှာ နံပါတ် (၁၊ ၂၊ ၃...) ပါတယ်။
· <ol> = Ordered List
· <li> = List Item

ဥပမာ - 

<ol>
    <li>မီးဖိုကိုဖွင့်ပါ။</li>
    <li>အိုးထဲသို့ ဆီထည့်ပါ။</li>
    <li>ကြက်ဥကို ခွဲထည့်ပါ။</li>
    <li>ဆားဖြူးပြီး မွှေပါ။</li>
</ol>
ရလာဒ် -
  1. မီးဖိုကိုဖွင့်ပါ။
  2. အိုးထဲသို့ ဆီထည့်ပါ။
  3. ကြက်ဥကို ခွဲထည့်ပါ။
  4. ဆားဖြူးပြီး မွှေပါ။

• <ol> Tag အတွက် Attributes

- ordered list မှာ " type " attribute ကို သုံးပြီး နံပါတ်စဉ်အစား အက္ခရာအလိုက် စာရင်းကို စီနိုင်ပါတယ်။
Ordered List type value (5) မျိုးရှိပါတယ်။(1, A, a, I, i)
- start Attribute ကို သုံးပြီး ကိုစတင်ချင်တဲ့ နေရာကို သတ်မှတ်လို့ ရပါတယ်။

ဥပမာ | Browser မှာ C. ပထမအချက်၊ D. ဒုတိယအချက် လို့ပြချင်တယ် ဆိုရင် - 

<ol type="A" start="3">
    <li>ပထမအချက်</li>
    <li>ဒုတိယအချက်</li>
</ol>
ရလာဒ် -
  1. ပထမအချက်
  2. ဒုတိယအချက်

(A=1, B=2, C=3 ကနေစတယ်)

C. Description List (ဖော်ပြချက် စာရင်း) – <dl>, <dt>, <dd>

HTML မှာ Description List (ဖော်ပြချက်စာရင်း) ဆိုတာ အသုံးအနှုန်းတစ်ခု (Term) နဲ့ ယင်းရဲ့ အဓိပ္ပာယ်ဖွင့်ဆိုချက် (Description/Definition) တွေကို တွဲဖက်ပြီး ပြသချင်တဲ့အခါ သုံးပါတယ်။
အဘိဓာန် (Dictionary) ပုံစံမျိုး၊ Glossary (ဝေါဟာရအဖွင့်များ) ဒါမှမဟုတ် မေးလေ့ရှိသောမေးခွန်းများ (FAQs) တွေအတွက် အသုံးများပါတယ်။
သူ့မှာ Bullet ဒါမှမဟုတ် နံပါတ်မပါဘူး။
သူ့ကို တည်ဆောက်ဖို့အတွက် Tag ၃ ခု ကို တွဲဖက်သုံးရပါမယ် -
• <dl> = Description List (ပင်မ စာရင်း)
• <dt> = Description Term (အဓိပ္ပာယ်ဖွင့်မယ့် စကားလုံး အသုံးအနှုန်း/ခေါင်းစဉ်)
• <dd> = Description Definition (အဲဒီစကားလုံးရဲ့ အဓိပ္ပာယ်)

ဥပမာ - 

<dl>
    <dt>HTML</dt>
    <dd>HyperText Markup Language – Web ရဲ့ အခြေခံအုတ်မြစ်</dd>
    
    <dt>CSS</dt>
    <dd>Cascading Style Sheets – Web ကို အလှဆင်ပေးတဲ့ဘာသာစကား</dd>
    >
    
    <dt>JavaScript</dt>
    <dd>Web ကို အသက်ဝင်စေတဲ့ ပရိုဂရမ်းမင်းဘာသာစကား</dd>
</dl>
ရလာဒ် -
HTML
HyperText Markup Language – Web ရဲ့ အခြေခံအုတ်မြစ်
CSS
Cascading Style Sheets – Web ကို အလှဆင်ပေးတဲ့ဘာသာစကား
JavaScript
Web ကို အသက်ဝင်စေတဲ့ ပရိုဂရမ်းမင်းဘာသာစကား

D. Nested Lists (စာရင်းထဲမှာ စာရင်းထပ်ထည့်ခြင်း)

ဒါက အဆင့်ဆင့် (Hierarchy) ရှိတဲ့ အကြောင်းအရာတွေအတွက် အရမ်းအသုံးဝင်တယ်။ စာရင်းတစ်ခုရဲ့ li ထဲမှာ နောက်ထပ် ul (သို့) ol ကို ထပ်ထည့်လို့ရတယ်။

ဥပမာ - 

<ul>
    <li>
        စာရေးကိရိယာ
        <ul>
            <li>ဘောပင်</li>
            <li>ခဲတံ</li>
            <li>ဖျက်တံ</li>
        </ul>
    </li>
    <li>
        စာအုပ်
        <ul>
            <li>မြန်မာစာအုပ်</li>
            <li>အင်္ဂလိပ်စာအုပ်</li>
        </ul>
    </li>
</ul>
ရလာဒ် -
  • စာရေးကိရိယာ
    • ဘောပင်
    • ခဲတံ
    • ဖျက်တံ
  • စာအုပ်
    • မြန်မာစာအုပ်
    • အင်္ဂလိပ်စာအုပ်
