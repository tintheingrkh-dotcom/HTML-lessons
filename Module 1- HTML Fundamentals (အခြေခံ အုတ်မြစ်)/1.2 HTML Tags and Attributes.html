1.2: HTML Tags & Attributes

* HTMLမှာ စာသားကို browser က နားလည်အောင် Tags များကို အသုံးပြုရ။


1.Anatomy of a tag (Tag တစ်ခု၏ တည်ဆောက်ပုံ)

* Tag အများစုမှာ opening tag [<->] နဲ့ Closing tag [</->] tag အစုံလိုက်ရှိ။
* အဲ့ဒီ tag နှစ်ခုကြားမှာ ရေးချင်တဲ့ content ကိုရေး။
* content ပါဝင်တဲ့ tag အစုဝေအးကို Element လိုခေါ်ပါတယ်။


2.HTML Attributes (မွမ်းမံမှု)၏ သဘောတရား

* attribute က tag တစ်ခုချင်းစီကို စွမ်းဆောင်ရည် ပိုကောင်းအောင် သို့မဟုတ် ပြောင်းလဲနိုင်အောင် ထည့်ပေးရသည့် (additional information)
* attribute ကို opening tag ထဲမှာ အမြဲရေး [ex - <-(attribute)>] ။
* attribute က name="value" ဆိုပြီး အတွဲလိုက်လာ။
