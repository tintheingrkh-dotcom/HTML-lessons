Lesson 1.6: Advanced Text Tags (အထူးပြုစာသားများ)

* သာမန်စာသားတွေထက် ပိုပြီး လုပ်ဆောင်ချက် ထူးခြားတဲ့ အဆင့်မြင့်စာသားများ(ဥပမာ - ကောက်နုတ်ချက်တွေ၊ ကုဒ်တွေကို ရေးထားတဲ့အတိုင်း ပြတာတွေ၊ ဓာတုဗေဒနဲ့ သင်္ချာဖော်မြူလာတွေ)ရေးရာတွင် အသုံးပြုရသည့် Tag များဖြစ်သည်။

1. <blockquote> (ကောက်နှုတ်ချက်)

* တခြားစာအုပ်၊ ဝဘ်ဆိုက် သို့မဟုတ် လူတစ်ယောက်ယောက်ရဲ့ ပြောစကားကို ကောက်နုတ်ပြီး ကိုးကားချက် အနေနဲ့ ပြသချင်တဲ့အခါ သုံးပါတယ်။
* ဒီ tag ထဲကစာသားတွေကို browser က ညာဘက်အနည်းငယ်ရွေ့ပြီး သီးသန့် ခွဲထုတ်ပေးပါတယ်။
*ဥပမာ -

ဒါက ကောက်နှုတ်ချက်တစ်ခုဖြစ်ပါသည်။

2. <pre> (နဂို အတိုင်းပြစာသား - Preformatted Text)

* HTML မှာ စာရေးတဲ့အခါ space တွေ၊ enter တွေ အများကြီး သုံးထားရင် အဲ့ဒီနေရာလွတ်တွေ ကို အလိုအလျှောက် ဖျောက်လိုက်ပစ်လိုက်ပါတယ်။
* ကိုယ် ကီးဘုတ်ပေါ်မှာ ရိုက်ထားတဲ့ Space တွေ၊ Enter ခေါက်ထားတဲ့အတိုင်း ပုံစံမပျက် ပြစေချင်ရင် <pre> tag ကို သုံးရပါတယ်။
* အများအားဖြင့် ကဗျာတွေရေးရင် ဒါမှမဟုတ် ကွန်ပျူတာ Programming ကုဒ်တွေကို Website ပေါ်မှာ ပြချင်ရင် သုံးပါတယ်။
* ဥပမာ - 

ကဗျာတစ်ပုဒ်...
              အလယ်မှာ နေရာလွတ်
   အောက်က စာကြောင်း။

3. <code> (code ကို web မှာ ပြခြင်း)

* Website စာမျက်နှာပေါ်မှာ "ကွန်ပျူတာ Programming ကုဒ်" တွေကို သီးသန့် ပုံစံနဲ့ ပြသချင်တဲ့အခါ သုံး။
* pre tag နဲ့ တွဲသုံးရင် ပိုအဆင်ပြေပါတယ်။
ဥပမာ -


   <pre><code>
      <!DOCTYPE html>
      <html lang="my">
   
      <head>
         <meta charset="UTF-8">
         <meta name="viewport" content="width=device-width, initial-scale=1.0">
         <title>Lesson 1.6: Advanced Text Tags(အထူးပြုစာသားများ)</title>                    
      </head>
   </code></pre>

4. <sub> နှင့် <sup> (အောက်ညွှန်း နှင့် အထက်ညွှန်း)

* ဒီ tag တွေကိုတော့ သင်္ချာဖော်မြူလာတွေနဲ့ ဓာတုဗေဒ သင်္ကေတတွေ ရေးတဲ့အခါ အသုံးပါတယ်။
a. <sub>(Subscript) = အောက်ခြေမှာစာလုံး သေးသေး ကပ်ရေးချင်တဲ့ အခါသုံး -
H2O = H<sub>2</sub>O
2. <sup>(superscript) = အပေါ်ထိပ်မှာ စာလုံးသေးသေးလေး ကပ်ရေးချင်တဲ့ အချိန်သုံး -
X2 = X<sup>2</sup>
