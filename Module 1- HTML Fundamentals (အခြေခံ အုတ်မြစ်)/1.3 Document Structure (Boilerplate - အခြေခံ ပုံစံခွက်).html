1.3: Document Structure (Boilerplate - အခြေခံပုံစံခွက်)

* HTML ဖိုင်စရေးတာနဲ့ ပုံစံခွက်အရင်ချရပါမယ်။
* ဒီပုံစံခွက် က website တိုင်းရဲ့ မပါမဖြစ် အခြေခံအုတ်မြစ် ဖြစ်ပါတယ်။
**ဥပမာ ပုံစံခွက် --> 

<!DOCTYPE html>
<html>
<head>
    <title>ကျွန်ုပ်၏ ပထမဆုံး Website</title>
</head>
<body>
    <h1>မင်္ဂလာပါကမ္ဘာလောကကြီး။</h1>
    <p>ဒါကတော့ HTML အခြေခံပုံစံခွက် ဖြစ်ပါတယ်။</p>
</body>
</html>

**ဒါကတော့ web မှာ ပြသမယ့် ပုံစံဖြစ်ပါတယ် -->

မင်္ဂလာပါကမ္ဘာလောကကြီး။

ဒါကတော့ HTML အခြေခံပုံစံခွက် ဖြစ်ပါတယ်။



1.<!DOCTYPE html>

* ဒီcode က HTML code မဟုတ်ပါ။ ဒီဖိုင်က HTML:5 နဲ့ ရေးထားကြောင်း browser ကို အသိပေးတာဖြစ်တယ်။
* ဒီ code ကို ဖိုင်ရဲ့ ပထမဆုံး စာကြောင်းမှာ တစ်ကြိမ်ပဲ ရေးရ။

2.<html>...</html> (Element တွေရဲ့ အသက်သွေးကြော)

* ဒီ tag က HTML ဖိုင်ရဲ့ အသက်သွေးကြော ဖြစ်ပါတယ်။
* ကိုယ်ရဲ့ website မှာရေးမယ့် code တွေ အကုန်လုံးကို ဒီ tag ရဲ့အတွင်းထဲ မှာပဲ ရေးလို့ရပါမယ်။

3.<head>...</head> (The Brain / နောက်ကွယ်က ဦးနှောက်)

* ဒီအပိုင်းကတော့ website ရဲ့နောက်ကွယ်က အချက်အလက် (metadata)တွေ ရေးပေးရတဲ့နေရာဖြစ်ပါတယ်။
* ဒီထဲမှာ ရေးသမျှက website မျက်နှာပြင် Client ဆီမှာ ပြမှာ မဟုတ်ပါဘူး။ browser က နောက်ကွယ်မှာ အလုပ်လုပ် သွားမှာ ဖြစ်ပါတယ်။
* ဥပမာ- <title> Tag ကို သုံးပြီး Website ရဲ့ ခေါင်းစဉ် (Tab Bar မှာ ပြမယ့်စာ) ကို ဒီထဲမှာ ထည့်ရေးရသလိုမျိုးပါ။

4.<body>...</body> (The Body / မျက်မြင်ခန္ဓာကိုယ်)

* Website ပေါ်မှာ Client ကို မြင်စေချင်သမျှအရာ (စာသား၊ ပုံ၊ ခေါင်းစဉ်၊ ဗီဒီယို) အားလုံးကို ဒီ tag ထဲမှာပဲ ရေးရပါတယ်။
*အပေါ်က ကုဒ်နမူနာမှာဆိုရင် <h1> tag နဲ့ <p> tag တွေကို ဒီထဲမှာ ထည့်ထားတာ တွေ့ရမှာပါ။

**📝 အမြင်ပုံဖော်ချက် (Visual Structure)

HTML Structure ကို လူတစ်ယောက် ဒါမှမဟုတ် သေတ္တာတစ်လုံး အနေနဲ့ မြင်ကြည့်လို့ ရပါတယ်။

<html> ဆိုတဲ့ သေတ္တာကြီးထဲမှာ...
   <head> (မျက်စိနဲ့မမြင်ရတဲ့ စိတ်/ဦးနှောက်အပိုင်း) နဲ့
   <body> (မျက်စိနဲ့ မြင်ရတဲ့ ခန္ဓာကိုယ်အပိုင်း) 
ဆိုပြီး အပိုင်းကြီး (၂) ပိုင်း ခွဲထားတာ ဖြစ်ပါတယ်။
