Lesson 1.4: Headings & Typography(Heading Tag)

* website တစ်ခုမှာ သတင်းစာ၊ စာအုပ် လိုမျိုး ခေါင်းစဉ်ကြီး၊ ခေါင်းစဉ်ခွဲ၊ စာပိုဒ်ခွဲ စသဖြင့် အဆင့်အဆင့် ခွဲဖို့လို။
* HTMLမှာ ခေါင်းစဉ်ရေးဖို့အတွက် Heading Tag (<h>) (၆)မျိုးရှိပါတယ်။

Heading Tag (၆)မျိုးရဲ့ ကွာခြားချက်

* နံပါတ်ကြီးလေ စာလုံးသေးလေ။
ပုံစံ-

h1 = ဒါကတော့ အကြီးဆုံး ခေါင်းစဉ် (Heading 1) ဖြစ်ပါတယ်။

h2 = ဒါကတော့ ဒုတိယအကြီးဆုံး ခေါင်းစဉ် (Heading 2) ဖြစ်ပါတယ်။

h3 = ဒါကတော့ တတိယအကြီးဆုံး ခေါင်းစဉ် (Heading 3) ဖြစ်ပါတယ်။

h4 = ဒါကတော့ (Heading 4) ဖြစ်ပါတယ်။

h5 = ဒါကတော့ (Heading 5) ဖြစ်ပါတယ်။
h6 =ဒါကတော့ အသေးဆုံး ခေါင်းစဉ် (Heading 6) ဖြစ်ပါတယ်။

SEO (search Engine Optimization ) နှင့် ဆက်စပ်မှု

* Heading Tag တွေ ရဲ့ ရည်ရွယ်ချက်က စာလုံး ကြီးစေဖို့မဟုတ်။ စာလုံး အကြီး/အသေး ကို CSS နဲ့ ကြိုက်သလို ချိန်ညှိုနိုင်။
* website ရဲ့ အဆင့်ဆင့် အရေးပါမှု နဲ့ ဖွဲ့စည်းပုံ ကို သတ်မှတ်ရန် ရွယ်ရွယ်ထားခြင်းဖြစ်။
* Searching Bot (Google bot) တွေ website ကို လာရှာတဲ့အခါ ဒီ Heading Tag ကို ကြည့်ပြီး website ရဲ့ အကြောင်းအရာကို နားလည်စေပါတယ်။
* <h1> Tag ကို Webpage တစ်ခုမှာ တစ်ခါပဲ သုံးသင့်ပါတယ်။
* <h2> မှ <h6> ကို လိုအပ်သလို အဆင့်လိုက်သုံးသင့်။
* <h1> --> <h2> --> <h3> စသဖြင့် လိုအပ်သလို တစ်ဆင့်ချင်း သုံးသင့်။
* အဆင့်ကျော်ပြီး ခုန်သုံးတာမျိုး လုပ်ရင် SEO ကို ထိခိုက်နိုင်။
