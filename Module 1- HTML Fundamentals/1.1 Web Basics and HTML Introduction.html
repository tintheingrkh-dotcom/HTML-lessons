1.1: Web Basics & HTML Introduction

· web basics
· HTML ဆိုတာဘာလဲ ?

A. web Basics

i. Internet vs Web (အင်တာနက်နှင့် ဝဘ်)

internet နှင့် website မတူ။
internet = လမ်းမကြီး
Web / World Wide Web (WWW) = ကား

ii. Client & Server (အသုံးပြုသူနှင့် ဝန်ဆောင်မှုပေးသည့် စက်)

client = တောင်းဆိုသူ (ဖုန်း သို့မဟုတ် ကွန်ပြူတာ)
Server = အချက်အလက်များ သိမ်းဆည်းသည့်နေရာ/internet ချိတ်ဆက်ထားသည့် ကွန်ပြူတာကြီး

iii. Web Browser အလုပ်လုပ်ပုံ

1.request - client မှ တောင်းဆို
2. server ကနေ HTML ဖိုင်တွေကို ပြန်ပို့ပေး
3. browser ကနေ HTML ဖိုင်ကို ဖတ်ပြီး Clientကိုပြ

iv. website နှင့် webpage

webpage = စာမျက်နှာ တစ်ခု
website = ဆက်စပ်စာမျက်နှာ များ စုစည်းထား (စာအုပ်)

B. HTML ဆိုတာ ဘာလဲ ?

i. HTML- Hyper Text Markup Language
· HyperText = တစ်နေရာကနေ တစ်နေရာကို ခုန်သွားနိုင်တဲ့ စာသား (လင့်ခ်)။
· Markup = စာသားကို အဓိပ္ပာယ်သတ်မှတ်ပေးတဲ့ အမှတ်အသားများ (tags)။
· Language = စည်းမျဉ်းတွေနဲ့ ဖွဲ့စည်းထားတဲ့ ဘာသာစကား။
* ရိုးရိုးလေး ပြောရရင် – HTML က သင့်စာသားတွေကို "ဒါက ခေါင်းစဉ်" "ဒါက စာပိုဒ်"ဒါက "ပုံ" ဆိုပြီး browser ကို ပြောပြတဲ့ဘာသာစကားပါ။
*programming language မဟုတ်
*website တစ်ခုရဲ့ structure ကို သတ်မှတ်ပေးတဲ့ Markup Language

ii. websiteတစ်ခု အတွက် မရှိမဖြစ် သုံးကောင်

1.HTML- အိမ်ရဲ့ အုတ်မြစ်၊နံရံ၊တိုင်
2.CSS- အိမ် ကို ဆေးသုတ်၊အလှဆင်
3.JavaScript- အိမ်ရဲ့ မီးခလုတ်၊မီးသီး၊ရေပိုက်
