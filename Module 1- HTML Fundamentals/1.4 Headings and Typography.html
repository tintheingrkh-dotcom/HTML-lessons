1.4: Heading & Typography(ခေါင်းစဉ်များနှင့် စာသားအခြေခံပုံစံ)

Website မှာ ရေးထားတဲ့ အကြောင်းအရာ (Content) ကို စာဖတ်သူအတွက် လွယ်ကူ‌စေရန်၊ Google (SEO)အတွက် အထောက်အကူဖြစ်စေရန် အတွက် ခေါင်းစဉ် နဲ့ စာပိုဒ် တွေကို စနစ်တကျ သုံးတတ်ဖို့ အရေးကြီးပါတယ်။
• <h1> မှ <h6> ထိ အဆင့်ဆင့်သုံးပုံ (SEO အတွက် Heading Hierarchy)
• <p> (စာပိုဒ်)၊ <br> (စာကြောင်းချခြင်း)၊ <hr> (မျဉ်းကြောင်းခွဲခြင်း)
• Semantic vs Non-semantic စာသား Tag များ

A. Heading Tags

စာအုပ်တစ်အုပ်မှာ ခေါင်းစဉ်ကြီး၊ ခေါင်းစဉ်ငယ်၊ ခေါင်းစဉ်ခွဲ စသဖြင့် ရှိသလိုပါပဲ website မှာလည်း ခေါင်းစဉ်တွေကို သူ့နေရာနဲ့သူ သုံးရပါတယ်။
HTML မှာ ခေါင်းစဉ်ရေးဖို့ အတွက် Heading Tag (၆)မျိုးရှိပါတယ်။ Heading Tag ရဲ့ နံပါတ်နဲ့ အရွယ်အစားဟာ ပြောင်းပြန်ဖြစ်ပါတယ်။
ဥပမာ - 


<h1>ခေါင်းစဉ် အဆင့် ၁ (အကြီးဆုံး)</h1>
<h2>ခေါင်းစဉ် အဆင့် ၂</h2>
<h3>ခေါင်းစဉ် အဆင့် ၃</h3>
<h4>ခေါင်းစဉ် အဆင့် ၄</h4>
<h5>ခေါင်းစဉ် အဆင့် ၅</h5>
<h6>ခေါင်းစဉ် အဆင့် ၆ (အသေးဆုံး)</h6>

ရလာဒ် - 



ခေါင်းစဉ် အဆင့် ၁ (အကြီးဆုံး)


ခေါင်းစဉ် အဆင့် ၂


ခေါင်းစဉ် အဆင့် ၃


ခေါင်းစဉ် အဆင့် ၄


ခေါင်းစဉ် အဆင့် ၅


ခေါင်းစဉ် အဆင့် ၆ (အသေးဆုံး)

SEO စည်းမျည်းများ

i. webpage တစ်ခုမှာ h1 Tag ကို တစ်ခါပဲ သုံးပါ။

h1 Tag က စာမျက်နှာရဲ့ အဓိကအကြောင်းအရာ (Main Topic) ကို ကိုယ်စားပြုတယ်။ Google က ဒီ h1 Tag ထဲက စာသားကို အထူးအလေးထားတယ်။

ii. Heading Tag တွေရဲ့ ရည်ရွယ်ချက်

Heading Tag တွေက ခေါင်းစဉ်ရေးဖို့ သီးသန့် သုံးတာပါ။စာလုံးကြီးချင်ရင် နောက်ပိုင် CSS နဲ့ စာသားတွေကို စိတ်ကြိုက် အလှဆင်လို့ရပါတယ်။

iii. အဆင့်အတန်းအတိုင်း ဆင်းပါ။

h1 အောက်မှာ h2၊ h2 အောက်မှာ h3 ဆိုပြီး ကိန်းဂဏန်းအလိုက် ဆင်းသင့်တယ်။ h1 ကနေ h3 ကို ကျော်ပြီး သုံးတာမျိုး မလုပ်ပါနဲ့။စာအုပ်မှာ အခန်းကြီး (h1) မပါဘဲ အခန်းငယ် (h3) စလို့မရဘူး။ SEO ကို ထိခိုက်စေပါတယ်။

B. Paragraph - စာပိုဒ် (<p> Tag)

<p> Tag က စာပိုဒ် (Paragraph) အတွက် သုံးတယ်။ ဒါက Block-level Element ဖြစ်လို့ သူ့ရဲ့အထက်နဲ့အောက်မှာ နေရာလွတ် (Margin) အလိုအလျောက် ထည့်ပေးတယ်။

C. Line Break - စာကြောင်းချခြင်း (<br> Tag)

တစ်ခါတစ်ရံမှာ စာပိုဒ်အသစ် မစချင်ဘဲ စာကြောင်းတစ်ကြောင်းပဲ ချချင်တယ်။ ဥပမာ – ကဗျာ၊ လိပ်စာ၊ သီချင်းစာသားတွေမှာ သုံးတယ်။

D. Horizonal Line - အလျားလိုက်မျည်း (<hr> Tag)

ဒါကတော့ ရှင်းပါတယ် အလျှားလိုက် မျည်းတစ်ကြောင်း ဆွဲပေးမှာပါ။

E. Semantic vs Non-semantic - စာသားပုံစံ နှင့် အဓိပ္ပါယ် ကို ဖော်ပြသော Tag များ

i. Semantic Tag (အဓိပ္ပါယ် ဖော်ပြသော Tag)

ဒီ Tagတွေ က စာသားရဲ့ အဓိပ္ပာယ် (Meaning) ကို Browser နဲ့ Google (SEO) ကို ပြောပြတယ်။
• <strong> Tag = ဒီစာက အရမ်းအရေးကြီးတယ် လို့ အဓိပ္ပါယ်ရပါတယ်။ စာလုံးအထူ နဲ့ပြပေးတယ်။
• <em> Tag = အလေးပေး ဖတ်စေချင်သော စာသား။ စာလုံးစောင်းနဲ့ ပြပေးတယ်။

ii. Non-semantic Tag (အဓိပ္ပါယ်မဖော်ပြသော Tag)

ဒီ Tag‌ တွေက စာသားရဲ့ ပုံပန်းသဏ္ဍာန် (Style) ကိုပဲ ပြောင်းလဲပေးတယ်။ အဓိပ္ပာယ် မပါဘူး။
• <b> Tag = စာလုံးထူ ပြရုံသက်သက်သာ အသုံးပြုသည်။ မည်သည့် အဓိပ္ပါယကို မှ မဆောင်ပါ။
• <i> Tag = စာလုံးစောင်းဖြင့် ပြပေးရုံသာသုံးသည်။ မည်သည့် အဓိပ္ပါယ် မှ မဆောင်ပါ။
