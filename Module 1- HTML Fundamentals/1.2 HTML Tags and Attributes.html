1.2: HTML Tags & Attributes

· Tag တစ်ခုရဲ့ ခန္ဓာဗေဒ (Anatomy)
· Attributes (မွမ်းမံပစ္စည်းများ)
· Special Characters & Entities

A. Tag တစ်ခုရဲ့ ခန္ဓာဗေဒ (Anatomy of a Tag)

HTML Tag ဆိုတာ စာသားကို အဓိပ္ပာယ်သတ်မှတ်ပေးတဲ့ အမှတ်အသားပါ။
HTML Tag ကို အကြမ်းဖျင်းအားဖြင့် အဓိက ၂ မျိုး ခွဲခြားလေ့ရှိပါတယ်။
• Container / Paired Tags (ရိုးရိုး Tag)
• Self-Closing Tag(ကိုယ်တိုင်ပိတ်တဲ့ Tag)

i. Container / Paired Tags (ရိုးရိုး Tag)

အများအားဖြင့် ရိုးရိုး Tag တစ်ခုမှာ opening tag , content , closing tag ဆိုပြီး အစိတ်အပိုင်း (၃) ခုပါဝင်ပါတယ်။
ပုံသေနည်း -
<အဖွင့်Tag> အကြောင်းအရာ (Content) </အပိတ်Tag>
ဥပမာ -
<p>ဒါက စာပိုဒ်တစ်ခုပါ။</p> = ဒါက စာပိုဒ်တစ်ခုပါ။
ရှင်းလင်းချက် -
· <p> = အဖွင့်Tag (Opening Tag) – ဒါက စာပိုဒ်စတယ်လို့ Browser ကိုပြောတယ်။
· ဒါက စာပိုဒ်တစ်ခုပါ။ = အကြောင်းအရာ (Content) – Browser က ပြသမယ့် စာသား။
· </p> = အပိတ်Tag (Closing Tag) – ဒါက စာပိုဒ်ဆုံးသွားပြီလို့ Browser ကိုပြောတယ်။ (အပိတ်Tagမှာ slash / ပါတယ်။)
· content ပါဝင်တဲ့ tag ကို Element လိုခေါ်ပါတယ်။

ii. Self-Closing Tag(ကိုယ်တိုင်ပိတ်တဲ့ Tag)


တချို့ Tag တွေက အကြောင်းအရာ (Content) မပါဘူး။ သူတို့က ကိုယ်တိုင်ပဲ ပိတ်သွားတယ်။ ဒီလို tag တွေကိုEmpty tags (သို့မဟုတ်) Single Tag (သို့မဟုတ်) Self-Closing Tag လို့ခေါ်ပါတယ် -
<br> (စာကြောင်းချရန်)
<hr> (အလျားလိုက်မျဉ်းကြောင်းဆွဲရန်)
<img src="photo.jpg"> (ပုံထည့်ရန်)


B.HTML Attributes (Tag ကို အချက်အလက် ထပ်ထည့်ခြင်း)

တစ်ခါတစ်ရံမှာ Tag ကို ပိုပြီးအသေးစိတ်သတ်မှတ်ချင်တယ်။ ဥပမာ – ပုံရဲ့ အကျယ်က 300 pixel ထားပေးပါ ဆိုတာမျိုး။ ဒီလိုအခါ Attribute ကိုသုံးတယ်။
Attribute တွေက အဖွင့်Tag ထဲမှာပဲ နေရာယူတယ်။
Attribute တွေ ကို အကြမ်းအားဖြင့် (၂)မျိုးခွဲလို့ရပါတယ် -
• Element-Specific (Local) Attributes
• Global Attribute

i. Element-Specific Attribute

Tag တစ်ခု အတွက်သာ အလုပ်လုပ်ပေးတဲ့ Attribute ဖြစ်ပါတယ်။ ဒီ Attribute တွေကို တခြားနေရာက ခေါ်သုံးလို့ မရပါဘူး။
ပုံသေနည်း -
<tag attribute-name="attribute-value">Content</tag>
ဥပမာ -
<img src="cat.jpg"alt="ကြောင်လေးတစ်ကောင်"width="300">
ရှင်းလင်းချက် -
ဒီမှာ src, alt, width တွေက Attributes တွေပါ။
· <img> - Tag (self closing tag)
· src="cat.jpg" – ပုံဖိုင်ရဲ့တည်နေရာ
· alt="ကြောင်လေးတစ်ကောင်" – ပုံက error တစ်ခုခုကြောင့် မပြနိုင်ခဲ့ရင် ပြပေးမယ့်စာသား
· width="300" – ပုံရဲ့အကျယ် 300 pixel

ii. Global Attributes (နေရာတိုင်းသုံးလို့ရတဲ့ Attributes)

တချို့ Attribute တွေက HTML Tag အကုန်လုံးနီးပါးမှာ သုံးလို့ရတယ်။ သူတို့ကို Global Attributes လို့ခေါ်တယ်။ အရေးအကြီးဆုံး (၃) ခုက –
•id
•class
•style

• id

တစ်မျိုးတည်းသော (Unique) နာမည်ပေးတယ်။ တစ်မျက်နှာမှာ တစ်ခါပဲသုံးလို့ရတယ်။
<h1 id="main-title">မင်္ဂလာပါ</h1>

• class

အုပ်စုဖွဲ့ဖို့ နာမည်ပေးတယ်။ တစ်မျက်နှာမှာ အကြိမ်ကြိမ်သုံးလို့ရတယ်။
<p class="highlight">အရေးကြီးစာသား</p>

• style

တိုက်ရိုက် CSS ပုံစံသတ်မှတ်ဖို့။ (ဒါကို ခဏပဲသုံးပါ၊ နောက်ပိုင်း CSS နဲ့အစားထိုးပါ)
<p style="color:red;">ဒီစာလုံးက အနီရောင်ဖြစ်ပါတယ်။</p>

ဥပမာ -
<div id="header" class="container" style="background-color: lightblue;color:red;"> <h1>ကျွန်တော့် Website</h1> </div>

ရလဒ် -

ကျွန်တော့် Website

C. Special Characters & Entities (အထူးစာလုံးများ)

HTML မှာ တချို့စာလုံးတွေကို ရိုက်ရင် Browser က ရှုပ်သွားနိုင်တယ်။ ဥပမာ – <p> ဆိုတဲ့စာကို ပြချင်တယ်ဆိုရင် Browser က ဒါကို Tag လို့ထင်ပြီး code အနေနဲ့ ဖတ်လိုက်ပါတယ်။ ဒါကြောင့် browserမှာ စာသားအ‌နေနဲ့ ပြချင်တဲ့အခါ Entity (ကုဒ်နံပါတ်) တွေကိုသုံးရတယ်။
Entity တွေက & နဲ့စပြီး ; နဲ့ဆုံးပါတယ်။
အသုံးများတဲ့ Entity တွေ –
• <(Less Than) - &lt;
• >(greater Than) - &gt;
• &(and) - &amp;
• "(Quotation mark) - &quot;
• ©(copy right) - &copy;
•  (Non-breaking space) - &nbsp;(နေရာလွတ်ကျဲကျဲထားရန်)

Emoji ထည့်နည်း -
Emoji တွေကိုလည်း တိုက်ရိုက်ကူးထည့်လို့ရပါတယ်။ (သို့) Entity နံပါတ်သုံးလို့ရတယ်။

ကြယ်: ★ (Entity နဲ့ &#9733;)
