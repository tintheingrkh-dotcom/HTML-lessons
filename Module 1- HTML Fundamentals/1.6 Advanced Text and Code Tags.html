1.6: Advanced Text & code Tags

· <blockquote> (ကောက်နုတ်ချက်) နဲ့ <q> (အတိုကောက်ကိုးကားချက်)
· <pre> (ပုံစံမပျက်စာသား)
· Code-related tags: <code>, <kbd>, <samp>, <var>
· <abbr> (အတိုကောက်) နဲ့ <address> (ဆက်သွယ်ရန်)

A. ကိုးကားချက်များ (Quotations) – <blockquote> နဲ့ <q>

တစ်စုံတစ်ယောက်ရဲ့ စကား၊ စာအုပ်စာတမ်းကနေ ကောက်နုတ်ပြီး ကိုးကားတဲ့အခါ ဒီ Tag တွေကိုသုံးတယ်။

i. <blockquote> – ရှည်လျားတဲ့ ကိုးကားချက် (Block-level)

· ဒါက စာပိုဒ်တစ်ခုလုံး ဒါမှမဟုတ် စာပိုဒ်အုပ်စု တစ်ခုလုံးကို ကိုးကားချင်ရင် သုံးတယ်။
· Browser က ဒီစာသားကို သာမာန်စာသားထက် အနားသတ် (Margin) ပိုခြားပြီး ပြသပေးတယ်။
· cite ဆိုတဲ့ Attribute နဲ့ ဘယ်ကနေကောက်နုတ်လဲဆိုတဲ့ လိပ်စာ (URL) ကိုထည့်နိုင်တယ်။ (ဒါပေမယ့် စာမျက်နှာပေါ်မှာ မပါဘူး၊ နောက်ကွယ်ကပဲရှိတယ်)

ဥပမာ - 

<blockquote cite="https://www.example.com/စာအုပ်စာတမ်း">
    <p>ပညာသည် အလင်းဖြစ်၏။ မိုက်မဲမှုသည် အမှောင်ဖြစ်၏။</p>
    <p>ထို့ကြောင့် ပညာကို အစဉ်မပြတ် သင်ယူသင့်ပေသည်။</p>
</blockquote>
ရလဒ် -

ပညာသည် အလင်းဖြစ်၏။ မိုက်မဲမှုသည် အမှောင်ဖြစ်၏။

ထို့ကြောင့် ပညာကို အစဉ်မပြတ် သင်ယူသင့်ပေသည်။

ii. <q> – အတိုကောက် ကိုးကားချက် (Inline-level)

· ဒါက စာကြောင်းတိုတို ကိုးကားချင်ရင် သုံးတယ်။ · Browser က ဒီစာသားကို "မျက်တောင်အဖွင့်အပိတ်(Quotation Marks)" နဲ့ အလိုအလျောက်ပြပေးတယ်။

ဥပမာ - 

<:p>
    ဆရာက <q>HTML ဟာ Web ရဲ့ အခြေခံအုတ်မြစ်ပါ</q> လို့ ပြောခဲ့တယ်။
</p>
ရလာဒ် -

ဆရာကြီးက HTML ဟာ Web ရဲ့ အခြေခံအုတ်မြစ်ပါ လို့ ပြောခဲ့တယ်။

B. <pre> – ပုံစံမပျက်စာသား (Preformatted Text)

ဒီ Tag ကတော့ ရိုက်ထားတဲ့ နေရာလွတ် (Spaces) နဲ့ စာကြောင်းချ(Line breaks)တွေ ကို အတိအကျ ပြပေးတယ်။ (သာမာန် HTML က နေရာလွတ်‌တွေ များနေရင် တစ်ခုတည်းအဖြစ် ပြန်ချုံ့ပစ်တယ်) · ဒီ Tag ထဲက စာသားက Monospace ဖောင့် (စာလုံးတိုင်း အကျယ်တူ) နဲ့ ပြတယ်။ ကဗျာတွေ ရေးတဲ့အချိန် အဆင်ပြေတယ်။

C. Code-related Tags (Coding ဆိုင်ရာ Tag များ)

ဒီ Tag တွေက programming သင်တန်းသားတွေအတွက် အထူးသုံးဖို့ ရည်ရွယ်ထားတာပါ။ Browser က ဒါတွေကို Monospace ဖောင့်နဲ့ ပြပေးတယ်။ code တွေ ကို ဖော်ပြချင်တဲ့ အခါ သုံးတယ်။ Code အရှည်ကြီး ပြချင်တဲ့အခါ <pre> Tag နဲ့ တွဲသုံးရင် ပိုအဆင်ပြေပါတယ်။

i. <code> Tag – Code အတိုအစ (Inline)

• စာကြောင်းတစ်ကြောင်းအတွင်းမှာ Code အတိုအစ ကိုပြချင်ရင် သုံးတယ်။

ဥပမာ -

<p>JavaScript မှာ variable တစ်ခုကို <code>let x = 10;</code> လို့ သတ်မှတ်တယ်။</p>

ရလာဒ် -

JavaScript မှာ variable တစ်ခုကို let x = 10; လို့ သတ်မှတ်တယ်။

ii. <kbd> – ကီးဘုတ်ခလုတ် (Keyboard Input)

• သုံးစွဲသူက ကီးဘုတ်ပေါ်မှာ ဘာနှိပ်ရမလဲ ဆိုတာကို ပြချင်ရင် သုံးတယ်။

ဥပမာ -

ဖိုင်ကို ကူးဖို့ <kbd>Ctrl</kbd> + <kbd>C</kbd> ကိုနှိပ်ပါ။

ရလာဒ် -

ဖိုင်ကို ကူးဖို့ Ctrl + C ကိုနှိပ်ပါ။

iii. <samp> Tag – ရလာဒ်(Sample Output)

• ကွန်ပျူတာ ပရိုဂရမ်တစ်ခုက ဘာစာသားပြန်ထုတ်ပေးလဲ ဆိုတာကို ပြချင်ရင် သုံးတယ်။
• ဒီ tag ကို သုံးခြင်းက semantic web ဖြစ်စေပါတယ်။
• ရှာဖွေရေးအင်ဂျင်တွေ (Search Engines) နဲ့ Screen Reader တွေက ဒီစာသားဟာ ကွန်ပျူတာ output ဖြစ်တယ်ဆိုတာကို အလွယ်တကူ နားလည်သဘောပေါက်စေဖို့ ကူညီပေးပါတယ်။

ဥပမာ -

Terminal မှာ error ကျရင် <samp>Error 404: File not found</samp> ဆိုတဲ့ စာတန်းကို ပြလိမ့်မယ်။

ရလာဒ် -
"

Terminal မှာ error ကျရင် Error 404: File not found ဆိုတဲ့ စာတန်းကို ပြလိမ့်မယ်။

iv. <var> – ပြောင်းလဲနိုင်သောကိန်းရှင်များ (Variable)

• သင်္ချာ ဒါမှမဟုတ် programming ထဲက ကိန်းရှင် (Variable) ကိုပြချင်ရင် သုံးတယ်။
• "ဒီစာသားဟာ ကိန်းရှင် (Variable) တစ်ခုဖြစ်တယ်" ဆိုပြီး Browser နဲ့ Search Engine တွေကို အဓိပ္ပာယ် ဖွင့်ဆိုပေးတာ (Semantic) ဖြစ်ပါတယ်။ (ပုံမှန်အားဖြင့် Italic နဲ့ပြတယ်)

ဥပမာ - 

<p>
      <var>user_name</var> ဆိုတဲ့ variable ထဲမှာ အသုံးပြုသူရဲ့ နာမည်ကို သိမ်းဆည်းထားပါတယ်။
</p>
ရလာဒ် -

user_name ဆိုတဲ့ variable ထဲမှာ အသုံးပြုသူရဲ့ နာမည်ကို သိမ်းဆည်းထားပါတယ်။

D.<abbr> – အတိုကောက် (Abbreviation)

• ဒါက HTML၊ CSS၊ ASAP စတဲ့ အတိုကောက်စာလုံးတွေရဲ့ အပြည့်အစုံ (Full form) ကိုပြတယ်။
• သုံးစွဲသူက စာလုံးပေါ် Mouse နဲ့‌ထောက်လိုက်ရင် title ထဲမှာထည့်ထားတဲ့ အပြည့်အစုံက ပေါ်လာမယ်။ (Screen Reader အတွက်လည်း အရမ်းကောင်းတယ်)

ဥပမာ - 

<p>
    <abbr title="HyperText Markup Language">HTML</abbr> ကို လေ့လာနေတယ်။
</p>
ရလာဒ် -

HTML ကို လေ့လာနေတယ်။

E. <address> – ဆက်သွယ်ရန်အချက်အလက် (Contact Information)

• ဒီ Tag က စာရေးသူ (Author) ရဲ့ ဆက်သွယ်ရန် အချက်အလက်တွေကို ထည့်ဖို့သုံးတယ်။ (လိပ်စာ၊ ဖုန်းနံပါတ်၊ အီးမေးလ်)
• Browser က ဒီစာသားကို Italic နဲ့ ပြလေ့ရှိတယ်။
